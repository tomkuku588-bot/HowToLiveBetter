三、权限使用说明

当前版本不申请任何系统权限，包括网络、定位、通讯录、相机、麦克风、相册、文件存储、日历、蓝牙等。应用不具备联网能力，阅读、检索、筛选、收藏、打卡、待办、专注与统计全部在设备本地完成。

备份数据的导出与导入通过系统文件选择器完成，由用户主动选择文件位置，应用不因此申请额外存储权限。

四、第三方服务与数据共享

当前版本不接入第三方 SDK、广告服务、统计服务、账号服务、支付服务或云同步服务，不向任何第三方共享、传输用户数据。若后续版本新增第三方服务或联网能力，我们会在上线前更新本政策，并在应用或应用市场页面中说明服务名称、用途和数据处理范围。

五、数据查看、更正与删除

  • 查看：用户可在应用内查看收藏、最近阅读、阅读进度以及习惯、打卡与待办。
  • 更正：用户可在应用内取消收藏、调整阅读偏好、修改或删除习惯与待办条目。
  • 删除：用户可在应用内删除收藏、习惯、打卡与待办记录，也可通过系统设置清空应用数据或卸载应用，此时本地数据将一并删除且无法恢复；已导出的备份文件由用户自行删除。

3. Permission Use

This version does not request any system permissions, including network, location, contacts, camera, microphone, photos, file storage, calendar, or Bluetooth. The app has no networking capability; reading, searching, filtering, favoriting, check-ins, to-dos, focus sessions, and statistics all run locally on the device.

Backup export and import are done through the system file picker, with the file location chosen by the user; the app does not request any extra storage permission for this.

4. Third-Party Services and Data Sharing

This version does not integrate third-party SDKs, advertising, analytics, account services, payment services, or cloud sync, and does not share or transmit user data with any third party. If a later version adds third-party services or online capabilities, this policy will be updated before release and will describe the service name, purpose, and data scope in the app or app store listing.

5. Access, Correction, and Deletion

  • Access: users can view favorites, recently read items, reading progress, habits, check-ins, and to-dos in the app.
  • Correction: users can remove favorites, adjust reading preferences, and edit or delete habits and to-dos in the app.
  • Deletion: users can delete favorites, habits, check-in records, and to-dos in the app, or clear app data through system settings or uninstall the app; local data will be deleted as well and cannot be recovered. Exported backup files must be deleted by the user.

6. Policy Updates

If a later version adds accounts, online features, cloud sync, analytics, advertising, payment, third-party SDKs, or new system permissions, this policy will be updated before release. The updated policy will be available on this page or through the in-app entry.
